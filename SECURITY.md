# Reporting a security issue

Use the repository's private vulnerability reporting form if available. Include the affected version, Android build or host version, connection type, and the smallest reproduction. Redact private keys, pairing files, credentials, device identifiers, and unrelated logs.

The server runs over local stdio and inherits the permissions of its MCP client. Android actions run with the selected device and privilege. The paired USB bridge uses client certificates. Re-pair the bridge if a client key is exposed.
